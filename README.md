# IT Support Portfolio

Welcome to my IT Support Portfolio. This repository documents hands-on labs and troubleshooting scenarios related to technical support, service desk, and end-user support.

## Areas of Focus

- Windows 10/11 troubleshooting
- Microsoft 365 support
- Active Directory
- Networking and TCP/IP troubleshooting
- DNS and DHCP
- VPN troubleshooting
- PowerShell for IT support
- Service desk documentation
- Hardware and software troubleshooting

## Portfolio Projects

### 1. Windows Troubleshooting
Hands-on troubleshooting scenarios involving Windows system issues, disk management, services, networking, and common end-user problems.

### 2. Network Troubleshooting
Practical troubleshooting using tools such as `ipconfig`, `ping`, `tracert`, `nslookup`, and other Windows networking utilities.

### 3. Microsoft 365 Support
Support scenarios involving Microsoft 365, Outlook, Teams, user access, authentication, and common end-user issues.

### 4. PowerShell for IT Support
Basic PowerShell commands and scripts used for system information, troubleshooting, and administrative support tasks.

### 5. Service Desk Case Studies
Sample IT support incidents documented using a structured troubleshooting process: issue, impact, diagnosis, resolution, and validation.
